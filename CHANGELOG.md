## [2.0.0] - 2026-11-02
- Share one resource with multiple model-based recipients, each with its own ability.
- Resolve membership through the recipient's admission contract.
- Require explicit public audiences; empty recipient lists grant no access.
- Enforce expiration, revocation, passwords and use limits when resolving links.
- Remove grants when their resource is permanently deleted and revoke them on soft deletion.
- Add unique tokens and indexed resource and recipient lookups.
- Allow host applications to configure share and audience models.
- Replace the string-audience API and unreleased schema with typed audiences.
